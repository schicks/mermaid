Event Modeling diagram demo

Event Modeling diagrams visualize system behavior over time using swimlanes for different entity types. 

      eventmodeling
        title Shopping Cart Flow
        
        system Cart {
          event ItemAdded (productId)
          event ItemRemoved (itemId)
          event CartCleared
        }
        
        system Inventory {
          event InventoryChanged (productId quantity)
        }
        
        screen CartScreen [Cart View]
        command AddItem (productId)
        command RemoveItem (itemId)
        readmodel CartItems
        processor OrderProcessor
        
        CartScreen --> AddItem
        AddItem --> ItemAdded
        ItemAdded --> CartItems
        CartItems --> CartScreen
        CartScreen --> RemoveItem
        RemoveItem --> ItemRemoved
